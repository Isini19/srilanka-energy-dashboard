# Sri Lanka Energy Consumption Dashboard

> 📌 This is a learning project built to practice Power BI and data visualization skills.

## 📊 Project Overview
An interactive Power BI dashboard analyzing Sri Lanka's energy consumption trends over the years — covering electricity generation, renewable energy growth, fossil fuel dependency, and greenhouse gas emissions.

## 🎯 Objectives
- Analyze Sri Lanka's electricity generation and demand over time
- Compare fossil fuel vs renewable energy usage
- Visualize the impact of the 2022 energy crisis
- Identify trends in solar, hydro, and clean energy adoption

## 🛠️ Tools Used
- Power BI Desktop
- Microsoft Excel
- GitHub

## 📁 Dataset
- **Source:** [World Energy Consumption — Kaggle](https://www.kaggle.com/datasets/pralabhpoudel/world-energy-consumption)
- **License:** CC0 Public Domain
- **Filtered to:** Sri Lanka data (57 rows)
